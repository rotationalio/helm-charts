# Genoa

Includes charts and configuration for a Kubernetes job that is run either on its own  or as part of a Helm PreSync hook or an ArgoCD Sync Phase/Wave to set up the application environment before the deployment is executed.

Normally Genoa is included as as dependency chart of another application. Genoa functions tend to be application-specific. See the applications using Genoa for more details on their commands and setup.
